HolySplit 💩

Plan the party together. Settle actual spending fairly.

Yixin Liu · Live app · GitHub repository

1 / 10

The problem

The shopping list lives in a spreadsheet. Commitments live in chat. Reimbursements come later.

For a small event, the organizer must reconcile all three while guests can change plans and spend different amounts.

2 / 10

The HolySplit workflow

Create an eventTime, place, expected people
Share one linkFriends join without accounts
Prepare togetherClaim items, edit estimates, enter actuals
SettleCompute balances and suggested transfers

No bank or payment connection. The app calculates amounts; people transfer money separately.

3 / 10

Where it differs

Partiful and Evite make invitations and RSVP easy.

Splitwise records costs and simplifies debts.

HolySplit connects a shared pre-event purchase board to the post-event split.

Overlap is real. The combined workflow needs a user test to establish value.

4 / 10

Two AI paths, one verified ledger

Budget drafterSuggests rough rows from event context
Help agentReads guidance or the member’s own split
Human approvalSelects rows and enters actual costs
Settlement codeCalculates transfers from actual cents

The hosted model is configured as gpt-5.4-mini. A successful live trace and real token usage still need to be captured.

Real Barbecue: split actual costs

The app suggests reimbursements. It does not send money or verify completion.

7 / 10

Cost to run

Rule-based starter: no model API call.

AI budget draft: at most five requests per event and 1,800 output tokens per request. Help agent: 20 questions per member per event per day.

Configured model: gpt-5.4-mini. Input, cached, and output tokens and price per run: not yet measured.

The report provides the calculation method. The required numbers must come from real provider usage.

8 / 10

Safety in the current build

  • Opening an invitation no longer creates a guest automatically.
  • Guests can access only their invited event; actual spending is payer-owned.
  • A local test rejected a model-suggested $9,999,999.99 row before preview.
  • The organizer can revoke the invitation link or remove access.

The test simulates a bad model response; a live prompt-injection test remains pending.

9 / 10

Impact and next steps

HolySplit supported a real October 24 Barbecue. The organizer reported that the activity was a great success. A read-only production check found seven current participant profiles and an audit entry for 13 imported preparation rows. Cross-device use also exposed unwanted guest rows, which led to an explicit-join fix.

No measured time savings or consented participant quote yet. Run a small before-and-after pilot before making impact claims.

Confirm the Final Project source is visible in the linked repository before Canvas submission. The real Barbecue screenshots are included; verified AI token usage remains pending.
